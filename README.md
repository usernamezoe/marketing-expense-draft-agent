\# Expense Resolution Draft Agent



삼성전자 VD사업부 마케팅그룹 표준 서식을 기반으로 한 \*\*비용 품의서 초안 작성 및 자동 .docx 빌더 Agent\*\*입니다.



\## 🚀 설계 핵심 특징 (Token Cost Optimization)

\- \*\*로컬 파이썬 연산 엔진 연동\*\*: 표 수식 계산 및 레이아웃 정의를 로컬 파이썬 단에서 처리하여 LLM API 호출 횟수와 토큰 길이를 획기적으로 낮췄습니다. 

\- \*\*월별 크레딧 사용량 최소화\*\*: 최적화된 시스템 지침 설계를 통해 불필요한 반복 대화를 제한하고 비용 소모를 방지합니다.



\## 📂 저장소 파일 구조

\- `README.md`: 프로젝트 안내서

\- `SKILL.md`: 스킬 기능 정의 및 사내 최적화 가이드라인

\- `agents/openai.yaml`: 시스템 인스트럭션 및 크레딧 제한 조건 명시 파일

\- `scripts/docx\_generator.py`: 표준 양식(바탕체, 블루 헤더, 조밀한 여백) 반영 문서 생성 모듈
